
# Documentación del despliegue web

## Proyecto
Inventario Escolar - UVEG

## 1. Preparación de la aplicación
Se organizó el proyecto en carpetas para separar
los archivos HTML, CSS y JavaScript.

## 2. Optimización
Se verificaron los archivos estilo.min.css y
app.min.js, utilizados por la interfaz web.

## 3. Empaquetado
Se creó un paquete ZIP mediante el Explorador
de archivos de Windows.

El paquete se extrajo en una carpeta independiente
para verificar su funcionamiento.

## 4. Pruebas locales
Se utilizó Python para ejecutar un servidor HTTP
de pruebas.

Primera prueba:
http://localhost:8000

Segunda prueba:
http://localhost:8001

La interfaz se mostró correctamente en ambas pruebas.

## 5. Versionamiento
Se utilizó Git para registrar los cambios del
proyecto mediante commits descriptivos.

El repositorio remoto se alojará en GitHub.

## 6. Configuración del servidor
La configuración de Nginx se realizará en la
siguiente etapa de la actividad.

## Alcance
Este proyecto corresponde a una simulación
académica de despliegue web.
