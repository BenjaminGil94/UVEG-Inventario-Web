# Inventario Escolar
Proyecto ficticio de despliegue académico para los retos UVEG 2 y 3.
Incluye una página estática, backend Flask ilustrativo, SQL y Nginx.
El frontend utiliza datos de ejemplo y no está conectado al backend; el endpoint `/api/productos` ilustra la conexión MySQL por separado.
## Empaquetado
Se conserva la estructura `public/css`, `public/js`, `public/img` y se comprime en ZIP.
## Git propuesto
`git init`, `git add .`, `git commit -m "Estructura inicial"`.
No se ha creado repositorio remoto ni se ha iniciado un servidor de producción.
